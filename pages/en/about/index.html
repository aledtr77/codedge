About

My name is Alessandro, and I taught myself to code. At first, I was collecting notes and ideas, trying to work out how they connected. Trying to give them some shape was the first step towards CODEDGE.

I started in front-end as AI was becoming more common in development. Since then, I've also built tools and mobile apps. These days, I see myself more as an indie developer.

How this site is built

That effort to make sense of things became the site, growing one piece at a time alongside what I was learning. I tried to connect the topics and work through them for myself, in a way that helped me understand them. I hope this personal way of bringing them together might be useful to others too. The pages use HTML, CSS and JavaScript, assembled by Vite.

Over time, I also added tools, components and other resources, following the projects I was working on and the subjects I wanted to explore. The code is on GitHub if you'd like to take a look.

What you'll find here

If you need to look something up, the HTML, CSS and JavaScript glossaries have definitions, properties and methods. The tutorials bring together guides to Git and GitHub, browser DevTools, accessibility, deployment, technical SEO and language fundamentals. For everyday work, there are also tools, UI components with their code, and a snippet library to try and adapt to your own projects.

How I work

I use AI regularly while working on my projects. It helps me explore ideas, revise text and code, and consider alternatives. Then I review the results, decide what to keep or change, and keep iterating. When something doesn't work, I return to the code to understand how to fix it.

Once a change takes shape, I review it in the browser. I check that the affected features behave as expected, the interactions are clear, the page adapts to different devices, and the rest of the site still works. If I notice something unexpected, I go back to the code to find out why.
