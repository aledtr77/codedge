Who I am and what CODEDGE is

Hi, I'm Alessandro DTR, and CODEDGE is my own corner of the web. I come from front-end, and over time I've branched out into everything that orbits web development and digital technology. What you'll find here is material organized by topic, from language basics to the workflows you deal with every day, with the code always sitting next to the explanation. Most of it is about HTML, CSS and JavaScript, but it also covers the tools I use daily, accessibility, and what it takes to put a site online. I try to use ordinary words, because that's how I would have liked to find things when I started out. If you're teaching yourself, or you already work in the field and just need to check something quickly, you should feel at home. It isn't a course and it doesn't cover everything: it's a place to draw on when you need an answer, kept in order so that answer turns up fast. The site grows one piece at a time, and collaborations are always welcome: if you have a correction to suggest, an idea, or you fancy building something together, get in touch.

What's in the five sections

The site is split into five sections, so you can get to what you need quickly. Resources holds the HTML, CSS and JavaScript glossaries, to open when a property or a method won't come back to you, plus a snippet library ready to paste. Tools has utilities that run in your browser, with no sign-up and nothing uploaded to a server: compress images, pull a palette out of a photo, generate colors and gradients. UI Components covers navbars, forms, cards and scroll indicators with the full code, there to read and take away. Tutorials holds the longer walkthroughs, on Git and GitHub, browser DevTools, accessibility, deployment and technical SEO, while Templates collects my finished portfolio projects, which are for sale in my Etsy shop. Not much abstract theory, plenty of code to try for yourself.
