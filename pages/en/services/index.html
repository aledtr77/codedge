Method

The problem first, the code second.

Each stage leads to a concrete result. If a stage does not serve your project, we skip it.

  • Understand

    Goal, people, content and constraints. I ask the boring questions before the work starts, not after.

    Output A shared scope

  • Define

    Structure, features and priorities. We put in writing what is in the project and what is out.

    Output A clear direction

  • Build

    Design and code move together, with previews you can check along the way.

    Output A project you can try

  • Deliver

    The project goes live with instructions for using and updating it.

    Output Live project and instructions
