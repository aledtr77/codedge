Prima di iniziare

Con questa guida scriverai il tuo primo CSS e vedrai subito il risultato nel browser. Partirai da una scheda di servizio; nei capitoli successivi aggiungerai spazio, colore e un layout che si adatta alla larghezza disponibile.

Prima di iniziare: ti servono un browser e un editor di codice come Visual Studio Code. Nell’editor crei e modifichi i file; nel browser apri la pagina, ricarichi e controlli l’effetto. Se tag, classi ed elementi annidati sono nuovi, leggi prima la guida HTML.

Leggi una regola, osserva il risultato atteso e poi prova a cambiarla. La guida spiega i concetti principali; gli approfondimenti finali e la documentazione ti aiutano quando ti servono altri dettagli.

Il percorso breve

Per costruire subito la pagina, segui la prima regola, la prova con due file, i selettori, lo spazio della scheda, Grid, la media query e l’esercizio completo. Consulta gli altri capitoli quando incontri quei problemi.

Cosa costruirai

Inizierai con una scheda: titolo e paragrafo. Poi userai la stessa idea per tre schede di servizi. Quando c’è spazio saranno affiancate; su una finestra stretta staranno in colonna. Testi lunghi e link raggiungibili da tastiera resteranno utilizzabili.

Il primo passo è semplice: cambiare il colore del paragrafo e verificare il risultato.

1. Leggere una regola e capire cosa cambia

Domanda pratica: se un testo cambia colore, quale parte del codice ha deciso il colore e quali elementi riguarda? Impara a leggere una regola: non devi memorizzare ogni proprietà.

Una regola CSS contiene un selettore e un blocco tra parentesi graffe. Il selettore indica quali elementi riceveranno le dichiarazioni del blocco.

p {
  color: royalblue;
}
  • p è il selettore: trova tutti i paragrafi.
  • color: royalblue; è una dichiarazione: proprietà color, valore royalblue.

I due punti separano proprietà e valore. Il punto e virgola chiude la dichiarazione. Gli spazi e gli a capo servono a leggere meglio il codice.

Il browser ignora una dichiarazione con un valore non valido: color: 20px; non assegna un colore. Le altre dichiarazioni valide della regola continuano ad applicarsi.

Esempio interattivo

Cambiare il colore di un paragrafo

Il paragrafo ha sempre lo stesso testo. Con color: #8bc9ef il testo è azzurro; con color: #efb38b è arancione.

2. Collegare CSS e HTML: prima prova

Puoi scrivere CSS in un file esterno, in un elemento <style> dentro l’HTML o nell’attributo style di un singolo elemento. Partiamo dal file esterno: puoi riusare le regole e sai dove modificarle.

1. Crea due file nella stessa cartella

Apri la cartella nell’editor di codice e crea index.html e stile.css. Copia questo contenuto nel primo file:

<!doctype html>
<html lang="it">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>La mia prima scheda</title>
  <link rel="stylesheet" href="stile.css">
</head>
<body>
  <article class="scheda">
    <h1>Consulenza</h1>
    <p>Ti aiutiamo a definire le priorità.</p>
  </article>
</body>
</html>

2. Scrivi la regola CSS

Nel file stile.css scrivi:

p {
  color: royalblue;
}

3. Guarda il risultato

Apri index.html nel browser. Vedi il titolo “Consulenza” e, sotto, il paragrafo blu. Il tag <link> fa caricare stile.css; il selettore p trova il paragrafo e color ne cambia il colore. Cambia royalblue in tomato, salva il CSS e ricarica la pagina: il paragrafo diventa rosso. Se non cambia, controlla che i due file siano nella stessa cartella e che il nome in href sia esatto.

Gli altri due modi di scrivere CSS

Per una sola pagina puoi mettere una regola in <style> dentro <head>:

<style>
  p { color: royalblue; }
</style>

Per un singolo elemento puoi usare l’attributo style:

<p style="color: royalblue;">Testo blu</p>

Entrambi rendono blu il testo. Quando le regole si ripetono su più pagine, il file esterno è più facile da mantenere. Uno stile inline può prevalere su altre regole: lo vedrai nel capitolo sulla cascata.

3. Commenti nel CSS

Consultazione: i commenti aiutano chi legge il codice a capire una scelta. Confronta sempre la nota con ciò che fa davvero la regola.

Un commento è una nota per chi legge il codice. Il browser lo ignora quando applica gli stili, quindi il commento non cambia l'aspetto della pagina.

Un commento su una riga

Scrivi il testo tra /* e */:

/* Colore del testo dei paragrafi */
p {
  color: royalblue;
}

Il commento descrive la regola. È la dichiarazione color: royalblue; a rendere blu il testo dei paragrafi.

Un commento su più righe

Gli stessi simboli racchiudono anche un commento più lungo:

/* Il colore dei link deve rimanere
   leggibile sullo sfondo chiaro. */
a {
  color: darkblue;
}

La nota spiega la scelta del colore; la regola a applica darkblue al testo dei link. Chiudi sempre il commento con */, altrimenti anche il codice successivo può essere ignorato.

4. Scegliere quali elementi modificare: selettori

Una regola CSS deve sapere a quali elementi HTML applicarsi. Il selettore è la parte della regola che li individua. Vediamo un tipo alla volta: in ogni esempio il codice CSS cambia il colore del testo.

Selezionare tutti gli elementi di un tipo

Questo HTML contiene due paragrafi:

<p>Primo paragrafo</p>
<p>Secondo paragrafo</p>

Questa regola seleziona gli elementi p:

p {
  color: blue;
}

Risultato: entrambi i paragrafi sono blu, perché entrambi sono elementi p.

Selezionare gli elementi con una classe

Se vuoi cambiare solo alcuni paragrafi, puoi assegnare loro una classe. Qui solo il primo ha la classe avviso:

<p class="avviso">Primo paragrafo</p>
<p>Secondo paragrafo</p>

Nel CSS il punto prima del nome indica una classe:

.avviso {
  color: blue;
}

Risultato: il primo paragrafo è blu. Il secondo non cambia, perché non ha la classe avviso. Se aggiungi class="avviso" anche al secondo, entrambi diventano blu: una classe può essere usata su più elementi.

Altri selettori: ID

Selezionare un elemento con un ID

Un id identifica un singolo elemento nella pagina. Qui l'ID è assegnato solo al primo paragrafo:

<p id="introduzione">Primo paragrafo</p>
<p>Secondo paragrafo</p>

Nel CSS il simbolo # prima del nome indica un ID:

#introduzione {
  color: blue;
}

Risultato: solo il primo paragrafo è blu. Non assegnare lo stesso ID a più elementi della pagina.

Selezionare in base alla posizione nell'HTML

In questo esempio il primo paragrafo è dentro un contenitore con classe scheda; il secondo è fuori, dopo la chiusura del contenitore:

<div class="scheda">
  <p>Testo dentro la scheda</p>
</div>
<p>Testo fuori dalla scheda</p>
.scheda p {
  color: blue;
}

Risultato: il testo dentro la scheda è blu; quello fuori non cambia. Lo spazio in .scheda p significa: seleziona i paragrafi che si trovano dentro un elemento con classe scheda, anche se sono annidati più in profondità.

Altri selettori: figli, classi combinate e gruppi

Figlio diretto o elemento più interno?

Ora entrambi i paragrafi sono dentro la scheda, ma solo il primo è figlio diretto: il secondo è dentro una section.

<div class="scheda">
  <p>Figlio diretto</p>
  <section>
    <p>Dentro la section</p>
  </section>
</div>
.scheda > p {
  color: blue;
}

Risultato: solo «Figlio diretto» è blu. Il simbolo > seleziona qui i paragrafi direttamente dentro la scheda. Se al suo posto usi uno spazio, .scheda p, diventano blu entrambi.

Altri due modi di combinare i selettori

Un elemento può avere più classi. Qui il primo paragrafo ha sia avviso sia urgente; il secondo ha solo avviso:

<p class="avviso urgente">Primo paragrafo</p>
<p class="avviso">Secondo paragrafo</p>
.avviso.urgente {
  color: blue;
}

Risultato: solo il primo paragrafo è blu. Senza spazio, .avviso.urgente cerca un elemento che abbia entrambe le classi. Lo spazio nell'attributo HTML separa i nomi delle classi; lo spazio nel selettore CSS ha invece il significato visto sopra: «dentro».

Una virgola serve invece a elencare selezioni diverse. Con l'HTML e il CSS seguenti, sia il titolo sia il paragrafo diventano blu:

<h2>Titolo</h2>
<p>Paragrafo</p>
h2, p {
  color: blue;
}

La virgola applica la stessa dichiarazione a tutti gli h2 e a tutti i p; non richiede che siano uno dentro l'altro.

Controlla una modifica proposta dall'AI

Se chiedi «rendi blu il testo della scheda», controlla il selettore proposto: p riguarda tutti i paragrafi della pagina; .scheda p riguarda solo quelli dentro elementi con classe scheda. Se il selettore non corrisponde a nessun elemento dell'HTML, la regola non avrà effetto.

La stessa scheda: scegli il testo

Nella prima prova p cambiava tutti i paragrafi. Se vuoi cambiare solo quelli dentro una scheda, usa il selettore discendente:

.scheda p {
  color: royalblue;
}

Esempio interattivo

Colora tutti i paragrafi oppure uno solo

Ci sono due messaggi. Il primo ha la classe avviso; il secondo non ce l’ha. Con p diventano azzurri entrambi. Con .avviso diventa azzurro solo il primo. Scegli un selettore e confronta il risultato con l’HTML.

5. Capire quale regola prevale: cascata

Problema: chiedi all’AI un colore, ma nel browser ne vedi un altro. Prima di aggiungere nuove regole, controlla quale dichiarazione prevale e perché.

Quando più dichiarazioni assegnano valori diversi alla stessa proprietà dello stesso elemento, la cascata stabilisce quale valore usare. La scelta avviene per ogni proprietà: una regola può fornire il colore, un'altra la dimensione del testo.

Partiamo da dichiarazioni normali, senza !important, nello stesso foglio e senza @layer. In queste condizioni:

  1. Prevale il selettore con specificità maggiore.
  2. A parità di specificità, prevale la dichiarazione scritta dopo.
<p class="note">Testo / Text</p>
.note { color: orange; }
p { color: royalblue; }

Il testo è arancione. .note ha una classe e prevale su p, anche se p è scritto dopo.

Approfondimento: come si confronta la specificità

Come confrontare la specificità

Conta tre gruppi e confrontali da sinistra: ID; classi, attributi e pseudo-classi; tipi e pseudo-elementi. #intro vale (1,0,0), .note (0,1,0), p (0,0,1), .group p (0,1,1). Decide il primo gruppo diverso. Spazi e > non aggiungono specificità.

La cascata completa considera anche origine degli stili, importanza e livelli @layer prima della specificità. Gli stili inline normali prevalgono sulle regole normali dei fogli dell'autore. !important cambia la precedenza della dichiarazione, non la specificità del selettore. Non aggiungerlo senza aver individuato il conflitto.

Esempio interattivo

Specificità e ordine sono due criteri diversi

La classe .note prevale su p. Se entrambe le regole usano .note, prevale quella scritta dopo. I controlli mostrano i tre casi; la dichiarazione che perde è barrata.

6. Capire da dove arriva un valore: ereditarietà

Domanda pratica: perché il testo delle schede cambia colore anche senza una regola su ogni paragrafo? Alcuni valori passano dal contenitore ai figli.

Alcune proprietà passano dal genitore ai figli quando sul figlio non è specificato un valore. Questo meccanismo si chiama ereditarietà.

<div class="parent">
  <p>Testo / Text</p>
</div>
.parent {
  color: orange;
  border: 2px solid orange;
}

Il paragrafo eredita color: il testo è arancione. Non eredita border: il bordo compare solo attorno al genitore. Anche font-family e line-height si ereditano normalmente; width, margin e padding no.

Se scrivi p { color: royalblue; }, il paragrafo diventa blu. Un valore assegnato al figlio viene prima del valore ereditato, anche se il selettore del genitore è più specifico. Non c'è un confronto di specificità fra elementi diversi.

Approfondimento: inherit, initial e unset

inherit richiede il valore del genitore; initial usa il valore iniziale della proprietà; unset eredita le proprietà ereditabili e usa il valore iniziale per le altre. initial non significa «ripristina gli stili del browser».

Esempio interattivo

Il colore si eredita, il bordo no

Il genitore ha testo arancione e un bordo. Senza una regola propria, il paragrafo prende il colore del genitore. Assegnando un colore al paragrafo cambia solo il suo testo; il bordo resta sul genitore.

7. Capire come gli elementi si dispongono: flusso

Decisione: come si dispongono gli elementi prima di costruire un layout? Capire il flusso aiuta a riconoscere quando una soluzione generata sposta o nasconde contenuti.

Il flusso normale è il modo in cui il browser dispone gli elementi prima di usare Flexbox, Grid o posizionamento. Negli esempi usiamo testo orizzontale da sinistra a destra.

  • display: block: l'elemento inizia su una nuova riga e, con larghezza automatica, occupa lo spazio orizzontale disponibile. Paragrafi e div hanno normalmente questo comportamento.
  • display: inline: l'elemento partecipa alla riga di testo. Su un normale span, width e height non impostano le dimensioni.
  • display: inline-block: resta nella riga, ma accetta width e height.
  • display: none: l'elemento e i suoi discendenti non generano scatole e non occupano spazio nel layout. Normalmente scompaiono anche dall'albero di accessibilità.
<span class="item">A</span>
<span class="item">B</span>

Con .item { display: block; }, A e B occupano due righe. Con inline partecipano alla stessa riga, se c'è spazio. Cambia il comportamento della scatola; l'ordine nell'HTML resta lo stesso.

visibility: hidden nasconde l'elemento mantenendo lo spazio occupato. opacity: 0 lo rende trasparente, ma può lasciarlo cliccabile e raggiungibile da tastiera: non è un sostituto di display: none.

Esempio interattivo

display cambia il comportamento della scatola

Ogni elemento ha width: 80px. Con inline questa larghezza non si applica agli span. Con block si applica e ogni elemento inizia su una riga. Con inline-block si applica senza imporre una nuova riga.

8. Capire lo spazio occupato: Box Model

Problema: una scheda occupa più spazio del previsto. Contenuto, spazio interno, bordo e margine contribuiscono alla misura: controllali prima di ridurre le dimensioni a caso.

Le scatole degli elementi hanno quattro aree, dall'interno verso l'esterno:

  1. Contenuto: testo, immagine o elementi figli.
  2. Padding: spazio tra contenuto e bordo. Riceve lo sfondo dell'elemento.
  3. Border: bordo attorno a contenuto e padding.
  4. Margin: spazio esterno al bordo. È trasparente.
.box {
  width: 120px;
  padding: 10px;
  border: 2px solid;
  margin: 16px;
}

Con il valore iniziale box-sizing: content-box, width misura il contenuto. La larghezza fino al bordo esterno è 120 + 10 + 10 + 2 + 2 = 144px. I margini restano fuori: in questo esempio lo spazio orizzontale occupato, margini inclusi, è 176px.

Con box-sizing: border-box, i 120px includono contenuto, padding e bordo. Il contenuto si riduce a 96px. Il margine continua a restare fuori.

Proprietà abbreviate e margini verticali

padding: 10px 20px significa 10px sopra e sotto, 20px a destra e sinistra. Con quattro valori l'ordine è alto, destra, basso, sinistra.

Approfondimento: margini verticali

Nel flusso a blocchi, margini verticali adiacenti possono collassare: due margini positivi di 16px e 24px possono produrre 24px, non 40px. I margini fra elementi flex o grid non collassano.

La stessa scheda: aggiungi spazio

Questa regola aggiunge spazio interno e un bordo alla scheda. Il testo resta al suo interno:

.scheda {
  padding: 1.5rem;
  border: 1px solid #52616b;
}
Approfondimento: stili predefiniti e reset

Il browser applica alcuni stili anche senza il tuo CSS: per esempio, aggiunge margini al body e ai paragrafi. Questi valori possono variare tra browser e influire sulla disposizione degli elementi.

Per partire da una base più uniforme, molti progetti usano un reset CSS: un insieme di regole che modifica o rimuove alcuni stili predefiniti. Questo codice è solo un esempio per mostrare come può essere fatto un reset. Non è uno standard universale da copiare: ogni progetto ha una struttura e contenuti propri, quindi il reset va deciso in base alle sue esigenze.

*, *::before, *::after {
  box-sizing: border-box;
}

body, h1, h2, h3, h4, p, ul, ol, figure {
  margin: 0;
}

img {
  max-width: 100%;
  height: auto;
}

button, input, select, textarea {
  font: inherit;
}

La prima regola usa border-box per rendere più prevedibile il calcolo delle dimensioni. La seconda rimuove i margini predefiniti degli elementi elencati, così puoi definire tu gli spazi. Le immagini non superano la larghezza disponibile e i controlli dei moduli usano il font ereditato.

Esempio interattivo

width misura il contenuto oppure l’intera scatola

La scatola ha width: 120px, padding di 10px e bordo di 2px. Con content-box misura 144px fino al bordo; con border-box misura 120px. Le misure sotto l’anteprima sono calcolate dal browser.

9. Adattare misure e contenuti: unità e overflow

Domanda pratica: cosa succede quando lo schermo si restringe o il testo cresce? Misure e limiti determinano se la scheda si adatta, scorre o taglia il contenuto.

Una misura relativa ha bisogno di un riferimento. 50% non significa «metà schermo» in generale. Per width, negli esempi di questa guida, significa metà della larghezza del contenitore.

  • px: Pixel CSS, non necessariamente un pixel fisico dello schermo.
  • %: Il riferimento dipende dalla proprietà: per width, normalmente la larghezza del contenitore.
  • rem: La dimensione del font dell’elemento radice html.
  • em: Per font-size: il font del genitore. Per padding e molte altre misure: il font dell’elemento stesso.
  • vw / vh: 1vw è l’1% della larghezza del viewport; 1vh l’1% della sua altezza. Su mobile dvh segue l’altezza dinamica visibile.

Se html ha un font di 16px, 2rem sono 32px. Se il genitore ha un font di 20px, font-size: 1.5em sul figlio dà 30px; sullo stesso figlio, padding: 1em dà 30px.

Dimensioni automatiche e limiti

.box {
  width: 100%;
  max-width: 600px;
  min-height: 100px;
}

La scatola usa la larghezza del contenitore, fino a 600px. È alta almeno 100px e può crescere con il contenuto. height: 100px, invece, impone un'altezza che può non bastare per il testo.

Su un blocco nel flusso normale, width: auto adatta la larghezza allo spazio disponibile tenendo conto anche di padding, bordo e margini. width: 100% assegna una percentuale: con content-box padding e bordo si aggiungono.

Contenuto che supera lo spazio: overflow

overflow: visible lascia il contenuto visibile fuori dalla scatola; hidden lo ritaglia; auto permette lo scorrimento quando necessario. Per testo lungo senza spazi puoi usare overflow-wrap: anywhere. Non nascondere il debordo prima di averne capito la causa.

calc(100% - 2rem) combina misure diverse. clamp(1rem, 2vw, 1.5rem) sceglie il valore centrale mantenendolo tra il minimo e il massimo indicati.

Esempio interattivo

50% dipende dalla larghezza del contenitore

Il figlio ha width: 50%. Con un contenitore di 160px misura 80px; con uno di 240px misura 120px. Cambia la larghezza del genitore: la regola del figlio resta identica.

10. Rendere leggibili testo e colori

Decisione: testo e colori devono restare leggibili, non solo gradevoli nell’anteprima. Controlla dimensioni, contrasto e contenuti reali anche dopo aver ingrandito la pagina.

color imposta il colore del testo. background-color imposta lo sfondo della scatola. Sono proprietà indipendenti.

body {
  font-family: Arial, sans-serif;
  font-size: 1rem;
  line-height: 1.5;
  color: #222222;
  background-color: #ffffff;
}
p {
  max-width: 65ch;
}

font-family è una lista: il browser usa il primo font disponibile; sans-serif è una famiglia generica di riserva. font-size regola la dimensione; font-weight il peso, per esempio 400 normale e 700 grassetto.

line-height: 1.5, senza unità, indica un fattore: con testo di 16px l'altezza di riga è 24px. Ereditando il fattore, ogni figlio lo moltiplica per il proprio font. 65ch è una larghezza basata sulla misura del carattere «0» nel font usato, non un conteggio esatto di caratteri.

Puoi scrivere un colore con un nome (red), in esadecimale (#ff0000), con rgb(255 0 0) o hsl(0 100% 50%). rgb(255 0 0 / 50%) aggiunge trasparenza al solo colore. opacity: 0.5 rende invece semitrasparente l'intero elemento, figli compresi.

11. Verificare gli stati dei controlli

Domanda pratica: un pulsante è riconoscibile quando lo raggiungi con la tastiera? Verifica gli stati dei controlli, non soltanto il loro aspetto iniziale.

Un selettore può dipendere dagli attributi o dallo stato di un elemento:

  • [type="email"] seleziona gli elementi con quell'attributo e valore.
  • :hover seleziona l'elemento su cui si trova il puntatore.
  • :focus-visible seleziona un elemento con focus quando il browser ritiene necessario mostrarne l'indicatore, normalmente durante la navigazione da tastiera.
  • :first-child seleziona un elemento che è il primo figlio del suo genitore.
a:hover { color: orange; }
a:focus-visible { outline: 3px solid royalblue; }
input[type="email"] { border: 1px solid; }
li:first-child { font-weight: bold; }
.note::before { content: "→ "; }

Le pseudo-classi hanno un solo : e selezionano uno stato o una condizione. Gli pseudo-elementi, come ::before e ::after, hanno due : e permettono di stilizzare una parte generata dell'elemento. In questo esempio content aggiunge una freccia prima del testo. Tieni il contenuto essenziale nell'HTML.

Il focus indica quale controllo riceve i comandi della tastiera. Non eliminare l'indicatore senza fornirne uno visibile.

Esempio interattivo

Il selettore :focus corrisponde al controllo attivo

Fai clic sul campo oppure raggiungilo con Tab: compare il bordo azzurro definito da input:focus. Quando il focus esce dal campo, il bordo torna al valore di base. Qui usiamo :focus, che si applica sempre mentre il campo ha focus.

12. Disporre elementi in una direzione: Flexbox

Decisione: vuoi disporre pulsanti o elementi lungo una direzione, lasciandoli adattare allo spazio? Flexbox descrive questo comportamento; controlla anche cosa succede quando lo spazio finisce.

display: flex si applica al contenitore. I suoi figli diretti diventano elementi flex. Non serve impostare display: flex su ogni figlio.

.container {
  display: flex;
  flex-direction: row;
  gap: 12px;
  justify-content: flex-start;
  align-items: center;
}

Flexbox dispone i figli lungo un asse principale. flex-direction sceglie la direzione. Nei nostri esempi, con scrittura orizzontale, row è una riga e column è una colonna. L'altro asse si chiama trasversale.

  • justify-content allinea e distribuisce lo spazio libero lungo l'asse principale.
  • align-items allinea i figli lungo l'asse trasversale.
  • gap imposta la distanza fra i figli, senza aggiungere spazio ai bordi del contenitore.
  • flex-wrap: wrap permette di creare più righe quando lo spazio non basta. Il valore iniziale è nowrap.

Come i figli dividono lo spazio

Sui figli, flex-grow controlla la crescita nello spazio libero; flex-shrink la riduzione quando manca spazio; flex-basis la dimensione di partenza sull'asse principale. flex: 1 1 0 li imposta insieme: crescita 1, riduzione 1, base 0.

La dimensione minima automatica può impedire a un figlio di restringersi sotto la misura del contenuto. Quando il contenuto deve poter rientrare, controlla anche min-width: 0 e la gestione del testo. Flexbox può andare a capo, ma ogni riga distribuisce il proprio spazio: non crea colonne condivise fra righe diverse.

Esempio interattivo

row e column cambiano l’asse principale

Il contenitore ha tre figli diretti: A, B e C. Con row sono in riga; con column sono in colonna. Il gap resta 12px. Cambia solo flex-direction.

13. Organizzare schede in righe e colonne: Grid

Decisione: le schede devono condividere colonne e righe? Grid permette di definire questa struttura. Tre colonne nell’anteprima non garantiscono che il testo resti leggibile su mobile.

Con display: grid, i figli diretti diventano elementi di una griglia. Il contenitore definisce colonne e righe, dette anche tracce. Senza un posizionamento esplicito, il browser colloca i figli in ordine nelle celle disponibili.

.container {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 12px;
}

1fr 1fr definisce due colonne con la stessa quota dello spazio disponibile. fr rappresenta una frazione dello spazio rimasto dopo le misure fisse e i gap, rispettando i vincoli delle tracce. 1fr 2fr assegna alla seconda colonna il doppio della quota della prima.

repeat(3, 1fr) ripete tre volte 1fr. minmax(0, 1fr) imposta una colonna con minimo zero e massimo una frazione: evita che il minimo automatico della traccia la allarghi per contenuti lunghi. Il contenuto può comunque richiedere regole per andare a capo.

Sul figlio, grid-column: span 2 richiede due colonne. grid-row: span 2 richiede due righe. Il contenitore crea le tracce; il figlio indica quali occupare.

Quando scegliere Grid o Flexbox

Usa Flexbox quando vuoi distribuire elementi lungo una riga o una colonna. Usa Grid quando vuoi definire colonne e righe condivise. Puoi avere un contenitore grid e, dentro una sua cella, un contenitore flex.

Dalla scheda alle tre schede

Quando metti tre schede dentro .schede, Grid le dispone inizialmente in una colonna. Il contenitore decide il layout; le schede restano i suoi figli diretti:

.schede {
  display: grid;
  grid-template-columns: 1fr;
  gap: 1rem;
}

Esempio interattivo

Il contenitore definisce il numero di colonne

Ci sono quattro figli: A, B, C e D. Con due colonne formano due righe; con una colonna formano quattro righe. Ogni colonna riceve una quota uguale dello spazio disponibile.

14. Adattare la pagina allo spazio: media query

Decisione: come devono riorganizzarsi le schede quando lo spazio cambia? Una media query applica regole a una condizione; verifica il comportamento anche fra le larghezze scelte.

Una media query applica un gruppo di regole solo quando una condizione è vera. Il viewport è l'area in cui il browser mostra la pagina, misurata qui in pixel CSS.

.container {
  display: grid;
  grid-template-columns: 1fr;
  gap: 12px;
}
@media (min-width: 640px) {
  .container {
    grid-template-columns: 1fr 1fr;
  }
}

Sotto 640px la griglia ha una colonna. Da 640px inclusi ne ha due: min-width include la soglia. La regola nella media query non cancella le altre proprietà: display e gap continuano ad applicarsi.

Mobile first significa scrivere la base per le larghezze piccole e aggiungere modifiche per quelle maggiori. La soglia si chiama breakpoint: sceglila quando il contenuto richiede un cambiamento. 640px è la soglia di questo esempio, non una regola universale.

Il tag <meta name="viewport" content="width=device-width, initial-scale=1"> nell'HTML permette ai browser mobili di usare la larghezza del dispositivo come viewport di layout. Le misure fluide e i limiti max-width servono anche fra un breakpoint e l'altro.

Le stesse schede su uno schermo ampio

Con la stessa impostazione “prima una colonna”, il progetto finale passa a tre colonne da 800px. Qui la soglia è più alta dell’esempio a due colonne perché tre schede richiedono più spazio:

@media (min-width: 800px) {
  .schede { grid-template-columns: repeat(3, minmax(0, 1fr)); }
}

Esempio interattivo

La condizione cambia a 640px inclusi

A 639px vedi una colonna. A 640px vedi due colonne. I pulsanti impostano la larghezza reale della finestra dell’esempio; la regola CSS resta uguale.

15. Capire perché una regola non funziona

Prima di chiedere una correzione: descrivi risultato atteso, risultato osservato, larghezza della finestra e cosa deve rimanere invariato. Controlla poi il comportamento reale: una risposta plausibile dell’AI non è una verifica.

Apri gli strumenti di sviluppo del browser con Ispeziona sull'elemento. Le schede Styles/Stili mostrano le dichiarazioni; Computed/Calcolati mostra i valori risultanti. Procedi in questo ordine:

  1. Il file è caricato? Nella scheda Network/Rete controlla che il CSS risponda senza errori e che il percorso sia corretto.
  2. Il selettore corrisponde? Controlla tag, classi e annidamento dell'elemento selezionato.
  3. La dichiarazione è valida e prevale? Un avviso può indicare un valore non valido. Una dichiarazione barrata può essere stata superata da un'altra: trova quella attiva.
  4. Il valore è ereditato? Distingui le regole dell'elemento dai valori provenienti dai genitori.
  5. La proprietà agisce in questo contesto? width non dimensiona uno span inline; justify-content non distribuisce spazio libero se non ce n'è.
  6. Quanto misura la scatola? Leggi contenuto, padding, bordo e margine. Se c'è una media query, controlla la larghezza del viewport.

Modifica una dichiarazione alla volta e verifica il valore calcolato. Le modifiche fatte negli strumenti di sviluppo sono temporanee: riportale nel file CSS per conservarle.

19. Posizionare elementi e gestire sovrapposizioni

Problema: un’etichetta deve stare nell’angolo di una scheda, oppure un elemento copre altri contenuti. Verifica il riferimento della posizione e l’ordine delle sovrapposizioni.

position cambia il modo in cui un elemento partecipa al flusso e il riferimento dei suoi spostamenti.

  • static: comportamento iniziale. top, right, bottom e left non spostano l'elemento.
  • relative: conserva il proprio spazio nel flusso; gli spostamenti partono dalla posizione originale.
  • absolute: esce dal flusso, quindi gli altri elementi non gli riservano spazio. In questo esempio usa come riferimento l'antenato più vicino con position diverso da static.
  • fixed: esce dal flusso e normalmente usa il viewport come riferimento, restando fermo durante lo scorrimento.
  • sticky: conserva il proprio spazio e resta vincolato alla soglia indicata, per esempio top: 0, durante lo scorrimento nel contenitore pertinente e nei limiti del proprio blocco contenitore.
.parent {
  position: relative;
}
.child {
  position: absolute;
  top: 12px;
  right: 12px;
}

Il figlio viene posizionato a 12px dal lato superiore e destro del riferimento stabilito da .parent. position: relative, senza spostamenti, non muove il genitore. Altre proprietà, come transform, possono creare riferimenti anche per elementi absolute e fixed: controllale se il riferimento non è quello atteso.

Sovrapposizioni e z-index

z-index controlla l'ordine di sovrapposizione per elementi posizionati e per elementi flex o grid. Non è una graduatoria globale: opera nel contesto di sovrapposizione, o stacking context, a cui appartiene l'elemento. Proprietà come transform e opacity inferiore a 1 possono creare un contesto separato. Un figlio con z-index: 9999 resta dentro il contesto del genitore.

Esempio interattivo

absolute toglie l’elemento dal flusso

Con static, A occupa spazio e B viene dopo. Con absolute, A va nell’angolo del genitore e B risale nello spazio lasciato libero. Il genitore ha sempre position: relative.

20. Mantenere coerenti i valori: variabili CSS

Decisione: se cambia il colore principale, quali elementi devono aggiornarsi insieme? Le variabili rendono espliciti i valori condivisi, ma il loro ambito va controllato.

Una proprietà personalizzata, spesso chiamata variabile CSS, conserva un valore con un nome che inizia con --. var() usa quel valore in un'altra dichiarazione.

:root {
  --accent: royalblue;
}
.note {
  color: var(--accent, blue);
}
.section {
  --accent: orange;
}

:root seleziona la radice del documento, cioè html. Qui assegna un valore disponibile, tramite ereditarietà, ai discendenti. Una .note fuori da .section è blu; dentro .section è arancione perché eredita il valore ridefinito lì.

Le proprietà personalizzate partecipano alla cascata e, nella forma mostrata, si ereditano. Il secondo argomento di var(--accent, blue) è un valore di riserva per una variabile non definita. Non corregge un valore esistente ma inadatto alla proprietà: se --accent: 20px, color: var(--accent, blue) non usa automaticamente blue.

Esempio interattivo

Due elementi leggono lo stesso valore

A e B usano entrambi color: var(--accent). Cambiando --accent cambia il colore di entrambi. Le due dichiarazioni color restano identiche.

21. Valutare il movimento: transform e transition

Decisione: il movimento aiuta a capire l’interazione? Controlla che non renda difficile usare la pagina e rispetta la preferenza per un movimento ridotto.

Queste proprietà vengono dopo i fondamenti. transform cambia la rappresentazione di un elemento: può traslarlo, ruotarlo o scalarlo. translateX(8px) lo mostra 8px più a destra senza spostare gli elementi vicini nel flusso.

.box {
  transform: translateX(0);
  transition: transform 200ms ease;
}
.box:hover {
  transform: translateX(8px);
}
@media (prefers-reduced-motion: reduce) {
  .box { transition: none; }
}

transition interpola un cambiamento di valore: qui riguarda transform, dura 200 millisecondi e usa la progressione ease. Lo stato :hover cambia il valore; la transizione stabilisce il passaggio. Non modifica il valore finale.

Una transizione richiede un cambiamento e valori interpolabili. Un'animazione con @keyframes può invece definire una sequenza di valori. La media query prefers-reduced-motion permette di rispettare la preferenza di chi richiede meno movimento.
