# Agent Rules

## Git Commit and Push Behavior
- **Automatic Commits**: You may perform automatic git commits for changes you make.
- **NO Pushes**: DO NOT perform `git push` operations under any circumstances. Git push is strictly reserved for the user to execute from the terminal.
- **Nessun Push (Italiano)**: NON eseguire `git push` in nessun caso. Il push è riservato esclusivamente all'utente da eseguire tramite terminale.
