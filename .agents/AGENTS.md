# Agent Rules

## Git Commit and Push Behavior
- **Automatic Commits**: You may perform automatic git commits for changes you make.
- **No Automatic Pushes**: DO NOT perform automatic `git push` operations under any circumstances.
- **Push Confirmation**: Always wait for explicit user confirmation or input before executing `git push` or pushing changes to remote repositories.
- **Comportamento Git (Italiano)**: Effettua solo commit in automatico per le modifiche successive. NON fare push automatici di testa tua: aspetta sempre la conferma esplicita o l'input dell'utente prima di eseguire il push.
