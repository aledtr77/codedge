# Agent Rules

## Git Commit and Push Behavior
- **Automatic Commits**: You may perform automatic git commits for changes you make. All commit messages must be written in English only (never in Italian or any other language).
- **NO Pushes**: DO NOT perform `git push` operations under any circumstances. Git push is strictly reserved for the user to execute from the terminal.
- **Nessun Push (Italiano)**: NON eseguire `git push` in nessun caso. Il push è riservato esclusivamente all'utente da eseguire tramite terminale. Tutti i messaggi dei commit devono essere scritti esclusivamente in inglese.
